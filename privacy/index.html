มีผลใช้บังคับ: 27 สิงหาคม 2026

นโยบายนี้อธิบายว่าเว็บไซต์ sorasukt.com รวมถึงบริการ Tarot และ API ที่เกี่ยวข้อง เก็บรวบรวม ใช้ จัดเก็บ และเปิดเผยข้อมูลส่วนบุคคลอย่างไร เราพยายามเก็บข้อมูลเท่าที่จำเป็นต่อการให้บริการ และใช้มาตรการที่เหมาะสมเพื่อคุ้มครองข้อมูลของผู้ใช้งาน

1. ผู้ควบคุมข้อมูล

ผู้ให้บริการเว็บไซต์ sorasukt.com เป็นผู้ควบคุมข้อมูลส่วนบุคคลสำหรับข้อมูลที่ประมวลผลผ่านเว็บไซต์และบริการ Tarot ภายใต้นโยบายนี้ หากต้องการติดต่อเกี่ยวกับข้อมูลส่วนบุคคล สามารถติดต่อผ่านช่องทาง Contact บนหน้าเว็บไซต์หลักได้

2. ข้อมูลที่เราเก็บ

ข้อมูลบัญชี

  • ข้อมูลระบุตัวตนที่ได้รับจาก Auth0 เช่น user ID, ชื่อ, อีเมล, รูปโปรไฟล์ หรือข้อมูลที่ผู้ให้บริการเข้าสู่ระบบส่งมา
  • ข้อมูลสถานะการเข้าสู่ระบบและโทเคนที่ใช้เพื่อยืนยันตัวตนกับ API

ข้อมูลสำหรับบริการ Tarot และดวงประจำวัน

  • วันเดือนปีเกิด ซึ่งจำเป็นสำหรับฟีเจอร์สมาชิกบางส่วน
  • เวลาเกิด ซึ่งเป็นข้อมูลทางเลือก ผู้ใช้สามารถไม่ระบุได้
  • คำถามที่ผู้ใช้ส่งเพื่อขออ่านไพ่ ไพ่ที่เลือก ผลการอ่าน และผล Daily Tarot / Daily Horoscope
  • วันที่ตามเขตเวลา Asia/Bangkok ที่ใช้สำหรับกำหนดผลประจำวันและป้องกันการสร้างผลซ้ำ

ข้อมูลทางเทคนิค

ระบบอาจประมวลผลข้อมูลที่จำเป็นต่อความปลอดภัย การทำงานของ API และการตรวจสอบข้อผิดพลาด เช่น เวลาเรียกใช้งาน สถานะคำขอ และข้อมูลเครือข่ายที่ผู้ให้บริการโครงสร้างพื้นฐานจำเป็นต้องประมวลผล

3. เราใช้ข้อมูลเพื่ออะไร

  • สร้างและดูแลบัญชีผู้ใช้ รวมถึงการเข้าสู่ระบบและออกจากระบบ
  • ยืนยันสิทธิ์ก่อนเข้าถึงข้อมูลสมาชิก
  • สร้างคำอ่าน Tarot และ Daily Horoscope ที่สัมพันธ์กับข้อมูลที่ผู้ใช้ให้ไว้
  • จัดเก็บผลประจำวันเพื่อส่งผลเดิมกลับภายในวันเดียวกันและหลีกเลี่ยงการคำนวณด้วย AI ซ้ำโดยไม่จำเป็น
  • รักษาความปลอดภัย ป้องกันการใช้งานผิดปกติ และตรวจสอบความผิดพลาดของระบบ
  • ปรับปรุงประสบการณ์ใช้งานและความน่าเชื่อถือของบริการ
วันเกิด เวลาเกิด ไพ่ และคำถามของผู้ใช้ถูกใช้เพื่อการสร้างเนื้อหาเชิงสะท้อนและความบันเทิงเท่านั้น ไม่ได้ใช้เพื่อวินิจฉัยสุขภาพ ตัดสินคดี ให้คำแนะนำทางการเงิน หรือรับรองผลลัพธ์ในอนาคต

4. ผู้ให้บริการภายนอก

เราใช้ผู้ให้บริการภายนอกที่จำเป็นต่อการทำงานของบริการ ได้แก่:

  • Auth0 สำหรับการยืนยันตัวตนและจัดการบัญชีผู้ใช้
  • Cloudflare สำหรับ Workers, API, D1 และ R2 รวมถึงโครงสร้างพื้นฐานและการจัดเก็บข้อมูล
  • Google Gemini API สำหรับสร้างผลการอ่าน Tarot และดวงประจำวันจากข้อมูลที่จำเป็นต่อคำขอ

เราพยายามส่งข้อมูลไปยังผู้ให้บริการภายนอกเท่าที่จำเป็นต่อวัตถุประสงค์ของบริการ และไม่ใส่ Auth0 Client Secret หรือ Gemini API Key ไว้ในโค้ดฝั่งผู้ใช้

5. การใช้ AI และข้อมูลที่ส่งไป Gemini

เมื่อมีการสร้างคำอ่าน ระบบอาจส่งคำถาม ไพ่ที่เลือก วันเกิด เวลาเกิด (หากระบุ) และบริบทที่จำเป็นไปยัง Google Gemini API เพื่อสร้างผลลัพธ์ เราไม่ส่งข้อมูลอื่นที่ไม่จำเป็น เช่น Auth0 access token หรือข้อมูลรับรองลับของผู้ใช้ไปยังโมเดล AI

ผลจาก AI อาจมีความคลาดเคลื่อน ไม่สมบูรณ์ หรือไม่เหมาะกับสถานการณ์จริง ผู้ใช้ควรใช้วิจารณญาณและไม่พึ่งพาผลจาก AI สำหรับการตัดสินใจที่มีผลกระทบสูง

6. การจัดเก็บข้อมูล

ข้อมูลโปรไฟล์สมาชิกและผลประจำวันถูกออกแบบให้เก็บใน Cloudflare D1 ส่วน R2 สงวนไว้สำหรับไฟล์ บันทึก หรือข้อมูล archive ที่มีขนาดใหญ่กว่าในอนาคต ข้อมูลจะเก็บไว้ตราบเท่าที่จำเป็นต่อการให้บริการ การรักษาความปลอดภัย การแก้ไขข้อพิพาท หรือหน้าที่ตามกฎหมายที่เกี่ยวข้อง

ผล Daily Reading ใช้คีย์ตามบัญชีผู้ใช้และวันที่ประเทศไทย ระบบจึงไม่จำเป็นต้องลบผลเก่าทุกเที่ยงคืน และสามารถรองรับประวัติย้อนหลังได้หากมีฟีเจอร์ดังกล่าวในอนาคต

7. ความปลอดภัย

เราใช้การยืนยันตัวตนผ่าน Auth0 และตรวจสอบ JWT ฝั่ง Cloudflare Worker ก่อนเข้าถึง API สมาชิก ข้อมูลที่จัดเก็บใน D1 และ R2 อยู่ภายใต้มาตรการรักษาความปลอดภัยของ Cloudflare รวมถึงการเข้ารหัสระหว่างส่งข้อมูลและการเข้ารหัสข้อมูลที่จัดเก็บตามบริการที่เกี่ยวข้อง อย่างไรก็ตาม ไม่มีระบบออนไลน์ใดรับประกันความปลอดภัยได้ 100%

8. สิทธิของผู้ใช้

ภายใต้กฎหมายที่ใช้บังคับ ผู้ใช้อาจมีสิทธิขอเข้าถึง แก้ไข ลบ จำกัดหรือคัดค้านการประมวลผลข้อมูล ถอนความยินยอมในกรณีที่ใช้ความยินยอมเป็นฐาน หรือขอรับข้อมูลในรูปแบบที่กฎหมายกำหนด การใช้สิทธิบางประเภทอาจมีข้อจำกัดตามหน้าที่ตามกฎหมายหรือเหตุผลด้านความปลอดภัย

หากต้องการใช้สิทธิหรือลบบัญชีและข้อมูลที่เกี่ยวข้อง โปรดติดต่อผ่านช่องทาง Contact ของเว็บไซต์หลัก

9. ผู้เยาว์

ผู้ใช้ที่ยังไม่บรรลุนิติภาวะควรใช้บริการภายใต้คำแนะนำหรือความยินยอมของผู้ปกครองตามที่กฎหมายกำหนด และไม่ควรเปิดเผยข้อมูลส่วนบุคคลเกินความจำเป็น

10. การเปลี่ยนแปลงนโยบาย

เราอาจแก้ไขนโยบายนี้เมื่อบริการ เทคโนโลยี ผู้ให้บริการ หรือข้อกำหนดทางกฎหมายเปลี่ยนแปลง วันที่มีผลใช้บังคับด้านบนจะแสดงเวอร์ชันล่าสุดที่เผยแพร่
